# KBG Visual Style


## Overall Feeling

KBG should feel:

- Dark
- Mysterious
- Intelligent
- Premium
- Cinematic
- Slightly terrifying


Reference feeling:

A secret AI intelligence system combined with luxury branding and dark fantasy.


---


# Design Principles


## Dark Atmosphere

The interface should use:

- Deep black backgrounds
- High contrast
- Controlled lighting


## Rounded Geometry

All elements should use:

- Soft rounded corners
- Premium smooth shapes
- No sharp cheap UI appearance


## Space

Layout should have:

- Medium to large empty spaces
- Breathing room
- Minimal crowded sections


## Shadows

Use:

- Deep shadows
- Layered depth
- Floating elements


## Dimension

The complete experience should feel:

8D / spatial / immersive


Elements should feel separated from the background.
