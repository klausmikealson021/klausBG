# KBG Brand Guide Card System


## Purpose

Cards are interactive brand guide modules.

Each card represents one brand concept.

User clicks/touches the card to reveal detailed information.


---


# Card Quantity


Current structure:

4 Sections

Each section:

3 Cards


Total:

12 Main Cards


---


# Default Card State


The default card contains:


1. Main Image

The card artwork itself.


2. Icon

A symbolic icon related to the topic.


3. Title

Main card name.


4. Subtitle

Short explanation or category.


---


# Card Independence


Cards should NOT be inside another visual container.

Each card must feel like:

- A standalone object
- Premium artifact
- Interactive object


---


# Card States


## Default

Normal resting state.

Contains:

- Artwork
- Icon
- Title
- Subtitle


---


## Hover / Touch

When user interacts:


Changes:

- Card slightly rises from background
- Depth increases
- Shadow becomes stronger
- Skeleton skull eyes glow with Fresh Arterial Red (#8A0303)


Additional effects:

- Subtle movement
- Cinematic lighting


---


## Open State


When clicked:


Card opens from the center.

Animation concept:

Like:

"Gate of hell opening"


Behavior:

- Card splits from center
- Left and right sides separate
- Smooth slow animation
- Content appears inside


---


# Card Content


After opening:

Card displays text content.


Maximum content:

300 words


Minimum content:

20 words


Because text length changes:

The content area must be dynamic.


The card must support:

- Short descriptions
- Long explanations


---


# Card Image Rule


The complete artwork must always be visible.

No cropping.

No cutting important parts.


Image behavior:

Contain mode.

Not:

Cover mode.


---


# Responsive Requirement


Cards must work on:

- Desktop
- Tablet
- Mobile


The complete card artwork must remain visible.
